# Claude Code Guidelines

## Commit Messages and PR Titles

Always use **Conventional Commits** format for all commit messages and pull request titles:

```
<type>: <description>
```

Common types: `feat`, `fix`, `chore`, `refactor`, `docs`, `style`, `test`, `perf`, `ci`

Examples:
- `feat: add mermaid block renderer with zoom/pan and syntax highlighting`
- `fix: use Astro scoped style to reliably pad mermaid code panel`
- `chore: update dependencies`
